# SpammApp.exe

SpammApp is a Windows desktop tool for WhatsApp messaging automation. It provides a graphical interface, customizable filtering rules, and improved performance compared with the original command-line version.

> Use SpammApp responsibly and only with the permissions required to contact recipients. Follow WhatsApp's terms of service and all applicable laws.

## Features

- GUI-based workflow in version 2.0.0
- Message automation tools
- Customizable filtering rules
- Improved performance
- Release history with an older command-line version
- Static website for product information and downloads

## Website

The website is made with plain HTML and CSS, so it does not require a build step or package installation.

Pages included:

- [Home](UI.html)
- [About](about.html)
- [Download](download.html)
- [Contact](contact.html)

The website uses [main.css](main.css) for its styling and [oid.ico](oid.ico) as its favicon and navigation icon.

## Download

The website currently links to these Windows application files:

- `SpammApp_v2.exe` - current GUI release, version 2.0.0
- `SpammApp_v1.exe` - older command-line release, version 1.0.0

Place the executable files in this project directory for the links in `download.html` to work, or upload them as assets to a GitHub Release and update the links accordingly.

### Recommended system

- Windows 10 or later
- 4 GB RAM
- 100 MB available storage
