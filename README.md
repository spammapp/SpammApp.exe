# SpammApp

SpammApp is a Windows desktop tool and landing page for WhatsApp messaging automation workflows. The project includes a polished marketing site and downloadable application builds for different versions.

## Overview

This repository contains:

- The SpammApp website built with static HTML and CSS
- Download links for the Windows executables
- About, contact, and support pages
- Release information for v1.0.0 and v2.0.0


## Features

- GUI-based messaging automation experience
- Clearer desktop-style interface compared to the original CLI version
- Flexible workflow rules and filtering options
- Improved performance in the latest release
- Download page with version history and system requirements

## Website Pages

- Home: overview and product positioning
- About: app story and evolution
- Download: latest release and version history
- Contact: support and feedback details


## System Requirements

Recommended for the latest version:

- Windows 10 or later
- 4 GB RAM
- 100 MB available storage

## Versions

- v2.0.0: Latest GUI release with improved performance and clearer rules
- v1.0.0: Original command-line version
